# 🎮 坦克大战 - Tank Battle

经典坦克大战 HTML 游戏，单人闯关模式。

## 🎯 游戏特色

- **单人闯关**：对抗一波比一波强大的 AI 敌方坦克
- **经典元素**：可破坏的砖墙、坚不可摧的钢墙、水域障碍
- **基地保护**：保护你的基地不被敌人摧毁
- **10 波挑战**：每波敌人更多、更快、更强
- **像素风格**：纯 Canvas 绘制，无需外部素材

## 🕹️ 操作方式

| 按键 | 操作 |
|------|------|
| `W` `A` `S` `D` / `↑` `←` `↓` `→` | 移动坦克 |
| `空格` | 射击 |
| `P` | 暂停/继续 |

## 🚀 开始游戏

1. 直接双击 `index.html` 在浏览器中打开
2. 点击"开始游戏"按钮
3. 消灭所有敌方坦克，保护你的基地！

## 📋 游戏元素

- 🟩 **绿色坦克** — 你的坦克
- 🟥 **红色坦克** — 敌方坦克（暗红色代表有额外生命）
- 🟫 **棕色方块** — 砖墙（可被子弹摧毁）
- ⬜ **银色方块** — 钢墙（不可摧毁）
- 🟦 **蓝色方块** — 水域（无法通过）
- 🏠 **基地** — 必须保护，被击中即游戏结束
